# Inventory

- **Script:** `S/inventory-codebase.ts`; one job, `inventory/profile-tech-stack`, and its review `review/review-agent-findings`. `next` lists the files first when they are not listed: it measures each file and records how Read sees it. A file whose encoding is not UTF-8 gets a decoded UTF-8 copy under the analysis root, which the job names as the file to read; records cite the source path and the logical line. Lines that are minified or encoded data are written, by the script, as `Unread` records, which account for them without anyone reading them.
- **What is out of scope:** only the request's Leave Out. The agent proposes no scope rule. `S/inventory-codebase.ts remaining` shows the folders still holding the most lines and what each Leave Out rule removes, and the run page lists files in scope that look vendored or generated, so the person can extend the Leave Out for the next run. The request's Supporting Material names documents that inform the run without being mapped.
- **At done:** tell the person what was read and left out, and go on to How it runs. If Inventory is refused (its checks still failing after its fix), the run stops there and says why: How it runs cannot start without its parts.
