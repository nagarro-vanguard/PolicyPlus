# Cancel the new value window with Escape

## Story

As a person using the product, I want pressing Escape in the window that asks for a value name and kind closes it as cancelled., so that a person can leave without adding a value..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: It closes as cancelled and no value is added.**
Given the new value window is open, when the person presses Escape, then it closes as cancelled and no value is added.
