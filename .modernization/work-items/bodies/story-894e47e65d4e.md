# Switch the number box between decimal and hexadecimal

## Story

As a person using the product, I want in the number window the person can show the number in decimal or hexadecimal, and Escape closes it as cancelled., so that registry numbers are often written in hexadecimal, so the person can read and type in either form..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: The same number is displayed in hexadecimal or decimal.**
Given the number window shows a number, when the person ticks or unticks Hexadecimal, then the same number is displayed in hexadecimal or decimal.

**AC-2: It closes as cancelled and the value is unchanged.**
Given the number window is open, when the person presses Escape, then it closes as cancelled and the value is unchanged.
