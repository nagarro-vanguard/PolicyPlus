# Name a new key in the key name window

## Story

As a person using the product, I want the key name window puts the cursor in the name box with its text selected, and Escape closes it as cancelled., so that the person can type a name straight away or back out without a mouse..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: The cursor is in the name box and any.**
Given the key name window appears, when it is shown, then the cursor is in the name box and any text in it is selected.

**AC-2: It closes as cancelled and no key is added.**
Given the key name window is open, when the person presses Escape, then it closes as cancelled and no key is added.
