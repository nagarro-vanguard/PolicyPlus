# Close the policy setting dialog and report changes

## Story

As a person using the product, I want cancel and other ways of closing the dialog report whether a change was made., so that the list behind the dialog refreshes only when a change was made, even if the person then cancels..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: The dialog closes reported as a change; otherwise as.**
Given Apply was used earlier in the session, when Cancel is pressed, then the dialog closes reported as a change; otherwise as a cancel.

**AC-2: It is still reported as a change.**
Given Apply was used earlier, when the dialog is closed by any other means, then it is still reported as a change.

## Out of scope

The other tasks of this part of the product have their own stories: Open a policy setting and see its current state; Fill in a policy's option values; Apply option values to a policy and keep the dialog open; Save a policy's state with OK.
