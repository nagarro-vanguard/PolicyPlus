# Open, reset or cancel the filter dialog

## Story

As a person using the product, I want the filter dialog opens showing the filter now in force; a person can reset every choice to its default, or press Escape to close it without changing the current filter., so that people can start over or back out without side effects..

## Context

This ports behaviour of the existing product, described in the attachment: 7 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: Policy type shows Any, Policy or Preference respectively.**
Given the current filter has no policy-type condition, or keeps only managed policies, or only the others, when the dialog opens, then Policy type shows Any, Policy or Preference respectively.

**AC-2: Current state shows Any or that state.**
Given the current filter has no state condition, or requires Not Configured, Configured, Enabled or Disabled, when the dialog opens, then Current state shows Any or that state.

**AC-3: Commented shows Any, Yes or No respectively.**
Given the current filter has no comment condition, or keeps only commented, or only uncommented policies, when the dialog opens, then Commented shows Any, Yes or No respectively.

**AC-4: Supported on is ticked, exactly the filter's products are.**
Given the current filter has a supported-on condition, when the dialog opens, then Supported on is ticked, exactly the filter's products are ticked, both matching options are set as the filter holds, and product branches whose tick differs from their parent are opened.

**AC-5: Supported on is unticked, both "Match a policy if.**
Given the current filter has no supported-on condition, when the dialog opens, then Supported on is unticked, both "Match a policy if at least one selected product is supported" and "Match policies with missing or blank support definitions" are ticked, and no product is ticked.

**AC-6: Policy type, Current state and Commented return to Any,.**
Given any choices in the filter dialog, when Reset is pressed, then Policy type, Current state and Commented return to Any, Supported on is unticked, both matching options are ticked and no product is ticked.

**AC-7: It closes as cancelled and the current filter is.**
Given the filter dialog is open, when Escape is pressed, then it closes as cancelled and the current filter is unchanged.

## Out of scope

The other tasks of this part of the product have their own stories: Choose the products a filter requires; Apply the options chosen in the filter dialog.
