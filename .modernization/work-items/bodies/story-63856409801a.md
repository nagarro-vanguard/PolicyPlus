# Propose the usual folder and allow another

## Story

As a person using the product, I want each time the download screen opens it proposes the Windows policy definitions folder, and a person can pick a different folder instead; cancelling the folder choice leaves the destination as it was., so that choosing another folder is rarely needed, so it stays an option the person can use only when wanted, without making it a step of the usual install..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: The destination is replaced by that folder.**
Given the download screen is open and no download is running, when the person chooses a folder in the folder dialog, then the destination is replaced by that folder.

**AC-2: The destination shows the Windows policy definitions folder every.**
Given the person opens the download screen, when it appears, then the destination shows the Windows policy definitions folder every time and no new policy folder is reported yet.

**AC-3: The destination stays unchanged.**
Given the folder dialog is open, when the person cancels it, then the destination stays unchanged.

## Out of scope

The other tasks of this part of the product have their own stories: Install Microsoft's policy definitions in one go.
