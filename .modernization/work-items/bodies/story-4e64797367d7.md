# Mark a selected value for deletion in one step

## Story

As a person using the product, I want let a person mark the value they have selected for deletion straight away, taking its name from the selection, so the policy file tells the machine to remove it., so that the most common removal needs no dialog and no typing, and the file keeps an instruction the machine follows when policies are applied..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Hold a policy file's settings in memory and answer questions about them.

## Acceptance criteria

**AC-1: The value is replaced by a deletion entry named.**
Given a value is selected in a policy file, when the person marks it for deletion, then the value is replaced by a deletion entry named "**del." followed by the value's name, taken from the selection without asking.

**AC-2: The value is removed on that machine.**
Given a value has been marked for deletion, when the policy file is saved and applied on a machine, then the value is removed on that machine.

**AC-3: The value is no longer erased from it but.**
Given a value is marked for deletion, when the person looks at the file, then the value is no longer erased from it but is represented by the deletion entry.

## Terminologies

- Deletion entry: A value named "**del." followed by the value name, which removes that value on the machine when policies are applied; it is not the same as forgetting the value, which leaves nothing in the file.
