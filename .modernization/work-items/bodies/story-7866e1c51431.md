# Download the fixed Microsoft policy template package

## Problem

- People who lack current policy definitions need them from Microsoft without hunting for the right download; a fixed package and secure connections keep the result predictable and safe.
- Open point: Should the download still allow TLS 1.0 and 1.1, which are long retired, or only TLS 1.2 and later?

## Goal

- Fetch the one Microsoft package of administrative templates, the Windows 11 September 2026 Update (26H2), into a scratch folder on the person's computer, through the service rather than the browser.

## Acceptance criteria

- Given the person starts the download, when it runs, then the Windows 11 September 2026 Update (26H2) administrative templates are saved as "W11Admx.msi" in a scratch folder under their local application data.
- Given the person wants another version, when they start the download, then no choice of version is offered and the same package is fetched.
- Given a download is made, when the connection is opened, then only TLS 1.0, 1.1 and 1.2 are accepted and no other protocol is used.
- Given the Microsoft site cannot be reached, when the download is started, then the failure is reported as a normal outcome and the screens never contact the site themselves.

## Scope

- packages/contracts (the Contracts layer)
- packages/domain (the Domain layer)
- packages/database (the Database layer)
- apps/api (the API service layer)
- packages/ui (the UI components layer)
- apps/web (the Web app layer)
- apps/e2e (the End-to-end tests layer)
- packages/tooling (the Tooling layer)

## Out of scope

- Anything a later story builds on top of this.
