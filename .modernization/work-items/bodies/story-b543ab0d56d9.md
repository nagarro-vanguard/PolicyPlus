# Cancel the list-of-text window with Escape

## Story

As a person using the product, I want pressing Escape in the window that edits a list of text closes it as cancelled., so that a person can leave the edit without changing the value..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: It closes as cancelled and the value is unchanged.**
Given the list-of-text window is open, when the person presses Escape, then it closes as cancelled and the value is unchanged.
