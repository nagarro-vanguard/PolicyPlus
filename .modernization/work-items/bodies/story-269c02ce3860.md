# Start a registry file import from the raw editor

## Story

As a person using the product, I want the Import button in the raw editor opens the registry file import window and refreshes the list when values were imported., so that administrators can bring registry export files into the policy file they are editing without leaving the editor..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Read and list values in policy files and registry policy keys; See and select the keys and values of a policy file; Read and write policy files with a byte-faithful round trip.

## Acceptance criteria

**AC-1: The registry file import window opens.**
Given the raw editor is open, when the person presses Import, then the registry file import window opens.

**AC-2: The list of keys and values is rebuilt to.**
Given the import window reports that values were imported, when it closes, then the list of keys and values is rebuilt to show them; otherwise it is left as it was.

## Out of scope

The other tasks of this part of the product have their own stories: See and select the keys and values of a policy file; Close the raw editor with Done or Escape; Add a key to a policy file; Add a value to the selected key; Edit the data of a value; Mark a value for deletion or clear a key; Forget a key or a value without leaving a deletion mark; Start a registry file export of the selected key.
