# Open the user and computer sources and remember them

## Problem

- People always return to the sources they were working with, and never end up stuck when those sources have gone.

## Goal

- The program closes open sources, opens the user and computer sources from the person's choice or the defaults, remembers the last choice, and falls back to the defaults when the saved sources cannot be reached.

## Acceptance criteria

- Given sources are already open, when new sources are opened, then the open ones are closed first; unsaved changes are discarded for sources backed by a POL file (local Group Policy files, a chosen POL file, a per-user Group Policy object) and for the empty source, while a registry source applies changes at once and a user hive file is applied when closed, so those lose nothing.
- Given first start with no saved policy sources, when the program opens, then both the user source and the computer source open as the local Group Policy files (Local GPO) with no extra location.
- Given the policy sources dialog opens with the last-used sources, when it shows, then each side is set to the remembered kind (Local GPO, Registry, POL file, Scratch space, and for users also per-user GPO or user hive), and the registry path, file name, SID or hive path is filled in only for kinds that carry one.
- Given the previously saved sources cannot be opened, when the program starts them, then the person is told "The previous policy sources are not accessible. The defaults will be loaded.", both sources are saved as Local GPO and opened quietly, and only the source type is reset while any saved location text stays.

## Scope
