# Confirm Find by ID and limit the area and selection choices

## Story

As a person using the product, I want go accepts Find by ID with the typed ID whether or not it matched, Escape closes it as cancelled, and the area choice, policy selection and menu offer only supported options., so that people decide when to go to what they found, or give up..

## Context

This ports behaviour of the existing product, described in the attachment: 5 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: It closes accepted with the typed text, even when.**
Given Find by ID is open, when Go is pressed, then it closes accepted with the typed text, even when nothing matched, so the caller may receive no selection.

**AC-2: It closes as cancelled.**
Given Find by ID is open, when Escape is pressed, then it closes as cancelled.

**AC-3: It offers only "User or Computer", "User" and "Computer".**
Given the area choice, when a person opens it, then it offers only "User or Computer", "User" and "Computer" and accepts no typed text.

**AC-4: Only that one is selected.**
Given the policy list, when a person selects a policy, then only that one is selected.

**AC-5: It is not offered.**
Given the main menu, when a person looks for Deduplicate Policies, then it is not offered.

## Out of scope

The other tasks of this part of the product have their own stories: Look up an identifier as it is typed.
