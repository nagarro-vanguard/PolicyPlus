# Merge identical user and computer policy pairs

## Story

As a person using the product, I want a person merges policy pairs that are the same for users and computers into single policies applying to both., so that templates often define the same setting twice; one entry per setting is easier to browse..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Show the category tree and the list of a chosen category; Work out whether a policy is enabled or disabled from its values; Show a policy's state and comment per area; Read and list values in policy files and registry policy keys; Decide whether a policy's support rules are met; Show category and policy details and keep the list tidy; Decide whether a policy is enabled, disabled or unsupported; Filter policies and keep search results; Refuse operations a REG file source cannot support; Read and write policy files with a byte-faithful round trip; Read support rules, products, classes and list options from templates; Open policy sources from imported files and describe them.

## Acceptance criteria

**AC-1: The first is removed and the second applies to.**
Given two policies alone in the same category under the same name, one for users and one for computers, with the same explanation text and registry key, when deduplicating, then the first is removed and the second applies to both sections.

**AC-2: They are told "Deduplicated N policies." with the number.**
Given the person chooses to deduplicate, when it finishes, then they are told "Deduplicated N policies." with the number merged.

## Terminologies

- Deduplication: Merging identical user and computer policy pairs into one; it is not deleting policies.

## Out of scope

The other tasks of this part of the product have their own stories: Load policy definitions from a folder or a single file; Browse categories and policies and read their descriptions; Choose which categories and areas the list shows; Open the lists of loaded files, support rules and products; Use the right-click menu on categories and policies.
