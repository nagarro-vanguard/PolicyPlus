# Show who made Policy Plus and which version this is

## Story

As a person using the product, I want a person opens the About box to see the author, the project web address and, when known, the version of the product., so that people can tell which build they are running and where to find the project..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: It names the author and the project web address,.**
Given a person opens the About box, when it appears, then it names the author and the project web address, and adds the version only when a version was built into the product.
