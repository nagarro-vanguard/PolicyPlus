# Choose how to delete a key in the delete window

## Story

As a person using the product, I want a window lets the person pick one of three ways to delete, and asks for a value name only when deleting one value., so that the choice must be clear before a key is changed, and a missing value name must be caught early..

## Context

This ports behaviour of the existing product, described in the attachment: 3 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: No option is chosen and pressing Delete with none.**
Given the delete window has just opened, when the person looks at it, then no option is chosen and pressing Delete with none chosen does nothing; choosing the option to clear the key or to delete all values under it and pressing Delete accepts the choice without further input.

**AC-2: They are told "You must enter a value name.".**
Given the option to delete one value is chosen, when the value name is empty and the person presses Delete, then they are told "You must enter a value name." and the window stays open; with a name, the choice is accepted.

**AC-3: The value name box cannot be typed in; when.**
Given the options are shown, when the option to delete one value is not chosen, then the value name box cannot be typed in; when it is chosen, it can.

**AC-4: It closes as cancelled and nothing changes.**
Given the delete window is open, when the person presses Escape, then it closes as cancelled and nothing changes.
