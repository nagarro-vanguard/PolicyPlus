# Add several template files to the loaded policies at once

## Story

As a person using the product, I want the person chooses one or several policy template files and each is added in turn to the policies already loaded, then sees which were added and which were refused with the reason for each., so that people can bring extra policies into their workspace in one go without emptying it or changing the folder the program remembers..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Load policy definitions from a folder or...: Definition load coordinator.

Open points, to settle before it is built:
- Does picking several files extend the single-file rule so that each file is added alone, with one failure reported per refused file?
- When several files are chosen and some are refused, are the other files still added?
- When several files are refused, are the failures shown together in one message or one after another?
- Are the structures built once after all files or after each file?

## Acceptance criteria

**AC-1: It offers administrative template files only and lets them.**
Given the person is adding template files, when the file chooser opens, then it offers administrative template files only and lets them pick one or several (several files extend the single-file choice the program offers today).

**AC-2: That file is added to the loaded policies, which.**
Given policies are already loaded, when the person confirms one template file, then that file is added to the loaded policies, which are kept and not emptied (the same file is added alone and the structures are built, as for a single file today).

**AC-3: The folder the program remembers for definitions is unchanged.**
Given template files were added, when the additions finish, then the folder the program remembers for definitions is unchanged.

**AC-4: The person sees "The ADMX file could not be.**
Given a chosen file is refused, when the additions finish, then the person sees "The ADMX file could not be added to the workspace." with the reason for that file.

## Terminologies

- Template file: A single administrative template file (ADMX) holding policy definitions; it is not a folder of templates or a language file.
