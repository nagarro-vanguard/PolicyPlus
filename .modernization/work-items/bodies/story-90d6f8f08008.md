# Choose the computer policy source

## Story

As a person using the product, I want in the policy sources dialog, the person chooses where the computer policies come from: the local Group Policy, a registry path, a POL file, or Scratch space. Each choice enables only its own box and Browse button, and the POL file is picked from the person's own machine., so that the person can see which computer source is active and cannot type into one that is not chosen..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

Open points, to settle before it is built:
- What is the content of the Local GPO choice, since decisions 1, 2 and 12 give no file-based replacement for the system's own policy folder: an uploaded Registry.pol, a stored copy, or is the choice not offered?

## Acceptance criteria

**AC-1: The registry path box is usable only with the.**
Given the person selects a computer choice, when the dialog updates, then the registry path box is usable only with the Registry choice, and the POL file name box and its Browse button only with the POL file choice.

**AC-2: It accepts only '.pol' files, allows naming a file.**
Given the person presses Browse for the computer POL file, when the file picker opens, then it accepts only '.pol' files, allows naming a file that does not exist yet, and does not ask before an existing file is chosen; the file comes from upload from the person's machine.

## Terminologies

- Policy source: The place where one side's policies are kept and saved back to: Local GPO, Registry, POL file, per-user GPO, user hive or Scratch space; it is not the template files that describe the policies.
- Scratch space: An empty source that can be changed but is never saved anywhere; it is not a file the person can download.

## Out of scope

The other tasks of this part of the product have their own stories: Choose the user policy source; Confirm or cancel the chosen policy sources.
