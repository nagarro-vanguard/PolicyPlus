# Forget a policy and list the registry values it touches

## Problem

- Not configured really means the source says nothing about the policy.

## Goal

- Work out every registry value a policy touches and drop them all when it is forgotten.

## Acceptance criteria

- Given a policy, when its touched values are listed, then they are its own value, its value lists, its elements' values (whole key for list elements) and checkbox and choice sub-lists, each once.
- Given a policy is forgotten, when it runs, then each list element's whole key is cleared and every touched value is dropped so it reads as Not configured.

## Scope

- packages/tooling (the Tooling layer)
- packages/domain (the Domain layer)
- packages/contracts (the Contracts layer)
- packages/data (the Data layer)
- apps/api (the Services layer)
- packages/ui (the Components layer)
- apps/web (the Screens layer)
- apps/e2e (the Black-box tests layer)

## Out of scope

- Anything a later story builds on top of this.
