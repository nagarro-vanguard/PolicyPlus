# Refuse unusable text searches and cancel with Escape

## Story

As a person using the product, I want find by text refuses an empty search or one with no attribute ticked, and closes as cancelled on Escape., so that people get a clear reason instead of an empty result..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: The search is refused with "Please enter search terms.".**
Given Find by text is open with empty search text, when Search is pressed, then the search is refused with "Please enter search terms."

**AC-2: The search is refused with "At least one attribute.**
Given In title, In description and In comment all start ticked, when none is ticked and Search is pressed, then the search is refused with "At least one attribute must be searched. Check one of the boxes and try again."

**AC-3: It closes as cancelled.**
Given Find by text is open, when Escape is pressed, then it closes as cancelled.

## Out of scope

The other tasks of this part of the product have their own stories: Find policies by title, description or comment text.
