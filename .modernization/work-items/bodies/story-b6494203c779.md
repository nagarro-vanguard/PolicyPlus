# Switch to the new definitions in one step

## Story

As a person using the product, I want once the new definitions are checked, empty the workspace, adopt the checked definitions, remember their folder as the definitions folder and present the category tree clean, with each problem listed., so that the person lands on a clean, predictable view of the new definitions, with the previous workspace emptied and the downloaded folder remembered..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Load policy definitions from a folder or...: Definition load coordinator; Find each template and its text in the perso...: Template folder scanner.

Open points, to settle before it is built:
- The rules do not say whether the switch is undone as a whole when the definitions folder cannot be remembered.
- The rules do not say whether the person sees each problem found while loading, or is asked whether to continue.
- The rules do not say that no category, policy or highlighted item is selected after the switch, that the information pane shows its empty message, or that earlier search results are forgotten.

## Acceptance criteria

**AC-1: The workspace is emptied, the downloaded folder loaded and.**
Given a successful download of definitions with a new folder, when the new definitions are adopted, then the workspace is emptied, the downloaded folder loaded and saved as the definitions folder, and the view rebuilt; given no new folder, then nothing changes.

## Out of scope

The other tasks of this part of the product have their own stories: Find each template and its text in the perso...: Template folder scanner; Find each template and its text in the person'...: Language file locator; Check every template is sound before using it; Work out categories, products, policies...: Definition structure builder; Offer the missing policy definitions once on first use; Show each policy's state and comment and apply the filters.
