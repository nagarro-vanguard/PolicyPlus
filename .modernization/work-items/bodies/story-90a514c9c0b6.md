# Ignore double-clicks on product ticks in the filter

## Story

As a person using the product, I want double-clicking a product's checkbox in the filter's product list does nothing, so the tick a person sees is always the tick that is kept., so that administrators build product filters quickly and must be able to trust what is ticked..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: Nothing changes and the tick shown is the tick.**
Given the product list in the filter dialog, when a person double-clicks a product's checkbox, then nothing changes and the tick shown is the tick kept.
