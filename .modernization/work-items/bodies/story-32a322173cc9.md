# Offer the download once, on first run, when definitions are incomplete

## Story

As a person using the product, I want the first time the program is shown, it offers to download Microsoft's policy definitions if the loaded ones look incomplete, and never considers the offer again., so that so a new person on an edition without the full definitions is led to the download, without being asked again on every visit..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Show the category tree and the list of a chosen category; Detect the Group Policy edition and read optional attributes.

Open points, to settle before it is built:
- How does the service know whether the person's Windows edition has Group Policy support, now that it runs on a server rather than on the person's computer?

## Acceptance criteria

**AC-1: The program records that it was considered, even when.**
Given the offer has not been considered, when the screen is shown, then the program records that it was considered, even when no offer is made, and never considers it again.

**AC-2: The person sees "Welcome to Policy Plus! Home editions.**
Given the offer is considered, the computer has no Group Policy support, and more than two non-empty categories name a parent that is not among the loaded definitions, when the screen is shown, then the person sees "Welcome to Policy Plus! Home editions do not come with the full set of policy definitions. Would you like to download them now? This can also be done later with Help | Acquire ADMX Files." and Yes opens the download window.

## Terminologies

- Welcome offer: The one-time question on first run whether to download Microsoft's definitions; not the Help menu item that does the same at any time.
- Orphaned category: A category whose definition names a parent that is not among the loaded definitions; not a category that is merely empty.
