# Choose the folder of policy definitions to load

## Story

As a person using the product, I want the person picks one folder of policy definitions from the standard Windows folder, the domain's shared folder when there is one, or a folder of their own. A folder that does not exist is refused when they confirm. They can back out without choosing anything., so that so that an administrator can point the workspace at the definitions they want to browse without a missing folder being accepted..

## Context

This ports behaviour of the existing product, described in the attachment: 4 rules it must keep and the reading of the code behind them.

Open points, to settle before it is built:
- When the person presses Browse and picks a folder, does it appear in the folder box? No rule states this.
- Should the choice show anything when no domain can be reached, beyond the domain folder not being selectable? No rule or decision states it.
- Is a missing folder checked before the person presses OK? No rule states an earlier check.

## Acceptance criteria

**AC-1: Their own folder choice is selected first.**
Given the person opens the choice of folder, when it appears, then their own folder choice is selected first.

**AC-2: The domain folder can be selected.**
Given the computer has joined a domain and the domain's policy definitions folder exists, when the choice appears, then the domain folder can be selected.

**AC-3: The domain folder cannot be selected.**
Given the computer has not joined a domain or the domain's policy definitions folder does not exist, when the choice appears, then the domain folder cannot be selected.

**AC-4: They cannot be used.**
Given the standard Windows folder or the domain folder is selected, when the person looks at the folder box and its Browse button, then they cannot be used.

**AC-5: They can be used.**
Given the person's own folder choice is selected, when the person looks at the folder box and its Browse button, then they can be used.

**AC-6: The folder to load is the one chosen.**
Given the person chose the standard Windows folder, the domain folder, or typed a folder, when they press OK, then the folder to load is the one chosen.

**AC-7: They see "The folder you specified does not exist.".**
Given the person typed a folder that does not exist, when they press OK, then they see "The folder you specified does not exist." and the dialog stays open.

**AC-8: It closes as cancelled with no folder chosen.**
Given the choice of folder is open, when the person presses Escape, then it closes as cancelled with no folder chosen.

## Terminologies

- Definitions folder: A folder holding policy definition files and their language texts that the workspace can load; not a policy file or a saved policy source.
- Domain folder: The shared policy definitions folder of the domain the computer has joined; not the standard Windows folder on the computer itself.
