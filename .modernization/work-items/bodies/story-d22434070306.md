# Forget a key or value entirely

## Story

As a person using the product, I want let a person remove a key with all its contents, after confirming, or a single value with its deletion entry from the policy file, leaving nothing behind., so that the policy reverts to saying nothing about what was forgotten, and a whole key is never removed without being asked first..

## Context

This ports behaviour of the existing product, described in the attachment: 1 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Hold a policy file's settings in memory and answer questions about them.

Open points, to settle before it is built:
- Is anything described or confirmed before a single value is forgotten?

## Acceptance criteria

**AC-1: They are asked "Are you sure you want to.**
Given a key is selected, when the person chooses to forget it, then they are asked "Are you sure you want to remove this key and all its contents?".

**AC-2: The key, all keys inside it, every value and.**
Given the person is asked to confirm forgetting a key, when they answer Yes, then the key, all keys inside it, every value and every clearing mark are removed from the file with no deletion left behind.

**AC-3: Nothing in the file changes.**
Given the person is asked to confirm forgetting a key, when they answer No, then nothing in the file changes.

**AC-4: The value and its deletion entry are both removed.**
Given a value is forgotten, then the value and its deletion entry are both removed from the file the same way.

## Terminologies

- Forget: Remove an entry from the file with no deletion instruction left behind; it is not the same as marking a value for deletion.

## Out of scope

The other tasks of this part of the product have their own stories: Add a new key to a policy file with its name checked; Add a new value to a policy file by its name and data together; Change the data of a value in a policy file in either number form; Remove a selected value or key by deletion entry or clearing; Export a policy source as a registry settings file.
