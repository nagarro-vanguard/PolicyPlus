# Move from a category to its parent category

## Story

As a person using the product, I want a person opens a category's parent from the category details window., so that it lets people walk up the category tree..

## Context

This ports behaviour of the existing product, described in the attachment: 0 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Open details of a policy, category, product or support rule.

## Acceptance criteria

**AC-1: The parent's details show in the same window.**
Given a category's details with a parent, when the person presses the parent button, then the parent's details show in the same window.
