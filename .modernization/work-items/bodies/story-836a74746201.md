# Show the limit in force and switch it on or off

## Story

As a person using the product, I want when a person opens the limit choices, they see the limit now in force: policy type, state, comment status and supported products, with a neutral value wherever the limit has no condition. Changing the limit options turns Only Filtered Policies on, and the person can switch it on or off from its menu; the view moves to the nearest category still shown., so that a person adjusting the limit starts from what is already narrowing their list instead of a blank form, and is never left looking at a category the limit has emptied..

## Context

This ports behaviour of the existing product, described in the attachment: 7 rules it must keep and the reading of the code behind them.

It relies on behaviour that other stories build first: Show each policy's state and comment and apply the filters; Browse products, their versions and details in one view; Open the chosen policy sources and keep the view on a visible category.

## Acceptance criteria

**AC-1: Policy type shows Any; given it keeps only managed.**
Given the limit has no policy-type condition, when the limit choices open, then Policy type shows Any; given it keeps only managed policies, then it shows Policy; given it keeps only the others, then it shows Preference.

**AC-2: Current state shows Any; otherwise it shows Not Configured,.**
Given the limit has no state condition, when the limit choices open, then Current state shows Any; otherwise it shows Not Configured, Configured, Enabled or Disabled as the limit holds.

**AC-3: Commented shows Any; given it keeps only commented policies,.**
Given the limit has no comment condition, when the limit choices open, then Commented shows Any; given it keeps only commented policies, then it shows Yes; given only uncommented ones, then it shows No.

**AC-4: Supported on is ticked, exactly the limit's products are.**
Given the limit has a supported-products condition, when the limit choices open, then Supported on is ticked, exactly the limit's products are ticked, both matching options are set as the limit holds, and product branches whose tick differs from their parent are opened.

**AC-5: Supported on is unticked, both "Match a policy if.**
Given the limit has no supported-products condition, when the limit choices open, then Supported on is unticked, both "Match a policy if at least one selected product is supported" and "Match policies with missing or blank support definitions" are ticked, and no product is ticked.

**AC-6: Only Filtered Policies is turned on and the view.**
Given a person changes the limit options, when the change is made, then Only Filtered Policies is turned on and the view moves to the nearest visible category.

**AC-7: The limit is applied or lifted and the view.**
Given a person uses the Only Filtered Policies menu, when they switch it on or off, then the limit is applied or lifted and the view moves to the nearest visible category.

## Terminologies

- Limit: The set of conditions (type, state, comment status, supported products) that narrows the policy list; it is not the choice of user or computer area.
- Only Filtered Policies: The switch that applies or lifts the limit on the policy list; it is not the limit's contents.
