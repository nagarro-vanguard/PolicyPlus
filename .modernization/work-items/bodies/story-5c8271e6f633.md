# Report how a search ended and let the person stop it

## Story

As a person using the product, I want stop or closing the window cancels a search, and the window reports how the search ended., so that people can abandon a long search and know what was covered..

## Context

This ports behaviour of the existing product, described in the attachment: 2 rules it must keep and the reading of the code behind them.

## Acceptance criteria

**AC-1: It reports "Finished searching: checked N policies, found M.**
Given a search ends, when it finishes or is stopped, then it reports "Finished searching: checked N policies, found M hits" or "Search canceled: ..." and Stop is disabled.

**AC-2: The search is cancelled; closing before it finishes leaves.**
Given a running search, when Stop is pressed or the window is closed, then the search is cancelled; closing before it finishes leaves "Search canceled" with the bar full.

## Out of scope

The other tasks of this part of the product have their own stories: Search every policy and list the hits as they are found; Choose a search result and reopen the results.
