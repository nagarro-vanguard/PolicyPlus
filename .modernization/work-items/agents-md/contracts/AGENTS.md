# Contracts: the Effect Schema types and HttpApi contract, and the OpenAPI document generated from it

Stack: services: Effect 4 HttpApi with Effect Schema, with an OpenAPI document generated from the same contract, served on Bun.

- Every request and response is an Effect Schema; the HttpApi group per capability is the only source of the OpenAPI document, regenerated by a script and checked for drift in CI.
- File content crosses the API as upload bodies and downloads with an explicit media type and size limit; the contract names the limit.

## Verify

- `bun run typecheck && bun run test && bun run openapi:check`
