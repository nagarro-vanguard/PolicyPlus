## What each criterion must keep

### AC-1

- Opening new policy sources first closes the ones already open. Unsaved changes are discarded for sources backed by a POL file (local Group Policy files, a chosen POL file, a per-user Group Policy object) and for the empty source. A registry source applies changes at once, and a user hive file is applied when it is closed, so those lose nothing. (PolicyPlus/Main.vb:311-315)

### AC-2

- On first start, when no policy sources were saved, both the user source and the computer source open as the local Group Policy files (Local GPO) with no extra location. (PolicyPlus/Main.vb:25-30)

### AC-3

- When the policy sources dialog opens with the last-used sources, each side is set to the remembered kind (Local GPO, Registry, POL file, Scratch space, and for users also per-user GPO or user hive), and the registry path, file name, SID or hive path is filled in only for the kinds that carry one. (PolicyPlus/OpenPol.vb:3-35)

### AC-4

- When the previously saved policy sources cannot be opened, the person is told "The previous policy sources are not accessible. The defaults will be loaded." and both sources are saved as Local GPO, then opened quietly. Only the source type is reset; any saved location text stays. (PolicyPlus/Main.vb:31-36)

- The comment file for a source sits beside its file: the POL file or hive path with the extension changed to .cmtx; for Local GPO or per-user GPO a file named comment.cmtx in the same folder; for the registry a file under the person's local application data folder (one for user, one for machine); Scratch space has none, so comments are unavailable. Built by: Work out where each source's policy and comment files live.
