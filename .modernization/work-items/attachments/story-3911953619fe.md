## What each criterion must keep

### AC-1

- A number entered for a registry value is limited to 0 to 4,294,967,295 for a 32-bit value and to 0 to 18,446,744,073,709,551,615 for a 64-bit value. (PolicyPlus/EditPolNumericData.vb:4-4)

### AC-2

- When a typed hexadecimal number is too large to fit, the value is set to the largest allowed value; text that is not a hexadecimal number leaves the value unchanged. (PolicyPlus/EditPolNumericData.vb:40-58)
