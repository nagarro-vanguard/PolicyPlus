## What each criterion must keep

### AC-1

- A policy's state in one area reads "Enabled", "Disabled", "Not Configured" or "Unknown"; the computer source is read for the computer area and the user source for any other. (PolicyPlus/Main.vb:257-266)

### AC-2

- With both areas shown, a policy that applies to both areas shows its common state followed by "(2)" when both match, the computer state followed by "(C)" when only the user is Not Configured, the user state followed by "(U)" when only the computer is Not Configured, and "Mixed" otherwise. (PolicyPlus/Main.vb:234-247)

### AC-3

- A filter on state keeps only policies whose state in the checked area is Configured (Enabled or Disabled), Not Configured, Disabled or Enabled, as chosen. (PolicyPlus/Main.vb:414-426)

### AC-4

- A policy's comment in one area is empty when that source has no comment file or holds no comment for the policy, and otherwise the saved text. (PolicyPlus/Main.vb:288-293)

### AC-5

- With both areas shown, the comment column is empty when neither area has a comment, shows "(multiple)" when both have one, and otherwise shows the single comment. (PolicyPlus/Main.vb:270-281)
