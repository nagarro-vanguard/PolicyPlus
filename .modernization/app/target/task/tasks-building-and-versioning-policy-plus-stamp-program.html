Ways we propose

Every build stamps itself

recommendedchosenautomate first

The version is worked out from the code by the system every time a copy is built or released, so nobody has to remember to stamp it.

Costs: Every build, even a throwaway one, now carries a version, so the rule that it can also be run by hand must still be offered.

Recommended because Removes a manual step that can be forgotten, so no released copy can carry an empty version, while keeping the committed record empty and every rule intact.

Why, and what it keeps

The system derives the version as part of building instead of waiting for someone to run a separate stamping step.

  • When the build script runs, it replaces the program's version in a generated source file with the text git gives for the current commit. That text is a tag, commit count and short commit name when tags exist, and a short commit name otherwise. The script runs when someone runs it or the release workflow does. The committed file holds an empty version.
