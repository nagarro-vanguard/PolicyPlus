Why, and what it keeps

Branch and prefix are filled in so only the file is required.

  • Export to a registry script is refused until a file name is given; the person is told "Please specify a filename and path for the exported REG."
  • The export dialog starts with the selected key as its source branch, or empty when nothing is selected. The branch can be typed over, and the export uses the text in the box at the time: an empty box exports all of the policy file.
  • The registry prefix box in the export dialog starts as HKEY_CURRENT_USER\ when the user policy source is being edited and HKEY_LOCAL_MACHINE\ otherwise. It can be changed, and the export uses the text in the box unchecked.

merged 3. Receive the settings file, or back out.

The system takes the source as is when it is a policy file, or rebuilds it from the three policy locations with each value keeping its type when it comes from the machine settings, writes it with removals and deletions marked and values in the exported-settings format, and tells the person it worked or only that it failed, letting the person retry. Backing out writes nothing.

takes the place of today's 3

Why, and what it keeps

Building and writing are one outcome for the person.

  • Exporting uses a source backed by a POL file as is. A registry-backed source (a chosen registry key or a loaded user hive file) is rebuilt as a new POL from the three policy locations: software\policies, software\microsoft\windows\currentversion\policies and system\currentcontrolset\policies. Any other source type is rejected, which no known source type reaches.
  • When a POL is built from a registry-backed source, every value and every sub-key under each of the three policy locations is copied with its own data type, with environment variables left unexpanded. A location missing from the registry stops the copy with an unhandled error.
  • Keys marked for removal are written to a REG file with a leading minus sign and values marked for deletion as a bare minus sign.
  • When a REG file is written, a default value is shown as an at sign, and quotes and backslashes in names and text are escaped. Text is written as quoted text and a 32-bit number as 'dword:' with eight hexadecimal digits. Every other type, including 64-bit numbers, expandable text and multiple strings, is written as hex bytes. Each carries its type number as hex(n), except plain binary, which is written as hex. Lines wrap before column 78 with a trailing backslash.
  • When the registry script is written, the person is told "REG exported successfully." and the dialog closes; on any failure they are told only "Failed to export REG!" and the dialog stays open.
What this way leaves out

An unsupported source raising an unhandled error is a defect that no known source reaches; the target reports any problem to the person plainly instead.
