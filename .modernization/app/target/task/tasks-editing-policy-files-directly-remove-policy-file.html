How it is done today

Worked out from the code, so each step says how sure we are. Marks are yours: what hurts, what is never used, what is wrong.

1. Mark a value for deletion, or clear a key

Replaces a value with a deletion entry, or on a key offers clear everything, clear first, or delete one value by name; nothing changes until a choice is made.

Stated by the code

2. Forget a key or value completely

After confirming for a key, removes the key, its sub-keys, values and marks, or the value and its deletion entry, leaving no deletion behind.

    kept 2. Say how a key is to be instructed

    For a key offers clear everything, clear then keep existing ordinary direct values, or delete one value; nothing is chosen at first, and confirming with none does nothing.

    takes the place of today's 1

    Why, and what it keeps

    Three real outcomes remain.

    • Deleting a key offers three choices, and OK does nothing until one is chosen; cancelling or Escape changes nothing. Clear everything removes all values and marks the key cleared. Clear first marks the key cleared and puts back only its existing direct values with ordinary content; deletion entries already in that key are lost and values of sub-keys are not put back. Delete one value is refused with "You must enter a value name." when the name is empty; otherwise any value of that name, whether or not it exists, is removed and replaced by a deletion entry.
    • When Delete is confirmed with the option to clear the key or to delete all values under it, the choice is accepted without further input; no option is chosen when the dialog opens, and confirming with none chosen does nothing.

    kept 3. Name the value to delete

    The name can be entered only when delete-one is chosen; an empty name is refused; otherwise the value, whether or not it exists, is replaced by a deletion entry.

    takes the place of today's 1

    Why, and what it keeps

    Only relevant inputs are open.

    • The value name box in the delete dialog can be typed in only while the option to delete one value is chosen.
    • When Delete is confirmed with the option to delete one value and the value name is empty, it is refused and the person is told "You must enter a value name."; with a name, the choice is accepted.
    • Deleting a single value from the list does not erase it from the file: it is replaced by a deletion entry named "**del." followed by the value name, which removes the value on the machine when policies are applied.

    kept 4. Forget an entry entirely

    Asks for confirmation to remove a key with its sub-keys, values and clearing marks, or a value with its deletion entry, leaving nothing behind; no changes nothing.

    takes the place of today's 2

    Why, and what it keeps

    Irreversible removal stays confirmed.

    • Forgetting a key asks "Are you sure you want to remove this key and all its contents?" and, on Yes, removes the key, all its sub-keys, every value and every clearing mark from the file with no deletion left behind; No changes nothing. Forgetting a value removes the value and its deletion entry the same way.
