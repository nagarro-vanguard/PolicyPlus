How it is done today

Worked out from the code, so each step says how sure we are. Marks are yours: what hurts, what is never used, what is wrong.

1. Say which kind of source holds the computer policies and where it is.

Makes available only the location detail that belongs to the chosen kind of computer source; for a policy file, offers files of the policy file type only, including one that does not exist yet.

Stated by the code

2. Say which kind of source holds the user policies and where it is: a policy file, a registry location, a user's profile hive or a user's own Group Policy object.

Makes available only the location detail that belongs to the chosen kind of user source; offers policy files of the policy file type, and hands the person on to pick a user profile or a user account when those kinds are chosen.

Stated by the code

3. Confirm the choices.

Creates the computer and user sources from the choices, falling back to a scratch space when none is chosen; if either cannot be created tells the person why and keeps the choice open, otherwise accepts both.

4. Abandon the choice without changing anything.

Closes the choice as cancelled.

Stated by the code

5. See the policies of the newly chosen sources.

Opens the sources, shows the opening result, and moves the view to the nearest visible category, dropping a selected policy that moved or is now hidden.

    merged 4. Confirm and start working

    Creates both sources; if either cannot be created, says which and why and stays open; otherwise opens them, shows the outcome, and moves to the nearest visible category.

    takes the place of today's 3, 5

    Why, and what it keeps

    Creating and opening happen when the person confirms, with one report.

    • When OK is pressed, the user source is created from the selected choice: Local GPO, Registry, POL file, per-user GPO (SID typed), user hive (file path typed), or Scratch space otherwise. If it cannot be created, the person is told "The user policy loader could not be created." followed by the reason, and the dialog stays open; the dialog closes as accepted only when both sources were created.
    • When OK is pressed, the computer source is created from the selected choice: Local GPO, Registry (path typed), POL file (name typed), or Scratch space when none of the others is selected. If it cannot be created, the person is told "The computer policy loader could not be created." followed by the reason, and the dialog stays open.
    • After the person chooses policy sources, they are opened with the opening result shown, and the view moves to the nearest visible category.
    • When a view setting changes, the program moves up to the nearest visible category, drops the selected policy if the move happened or the policy is now hidden, then rebuilds the tree and list. A policy kept after the move appears in the information pane only: rebuilding the list reselects the category in the tree, which clears the selection, so its row is not highlighted.
