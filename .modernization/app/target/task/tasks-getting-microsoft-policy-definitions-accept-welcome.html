Ways we propose

Offer once, keep it open

recommendedchosenautomate first

On first use the system works out whether definitions are lacking and makes a single offer, and if it is passed over the invitation stays quietly available.

Costs: Needs a standing invitation, which is more to design than a one-time question.

Recommended because The person is never lost if they decline once, the offer is still made only once, and the lack of definitions is worked out without asking.

inferred 2. Have missing definitions noticed without having to check.

Works out whether the edition lacks Group Policy support and whether more than two non-empty categories name a missing parent.

takes the place of today's 1, 2

Why, and what it keeps

The system decides on evidence so only people who need the offer see it.

  • The computer counts as having the Group Policy infrastructure only when the number Windows gives for its edition equals one of 59 fixed codes in a list. The edition is asked for as Windows version 6.0, and the result of the call is not checked. When the call fails the edition stays 0, which is not in the list, so the computer counts as having none.
  • A category is orphaned when it has no parent among the loaded definitions although its definition names one.
  • A category is empty when it holds no subcategories and no policies at all, counting hidden ones.
  • When the offer is considered, it is made only if this Windows edition has no Group Policy support and more than two non-empty categories name a parent that is not among the loaded definitions. The person sees "Welcome to Policy Plus! Home editions do not come with the full set of policy definitions. Would you like to download them now? This can also be done later with Help | Acquire ADMX Files."; Yes starts the download dialog.
