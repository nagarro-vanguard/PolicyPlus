How it is done today

Worked out from the code, so each step says how sure we are. Marks are yours: what hurts, what is never used, what is wrong.

1. Choose a value to change

Offers a text, number or list-of-text entry by the kind of the value, and refuses kinds such as binary.

Stated by the code

2. Enter the new data

Takes text, a list of lines, or a number within the limits of its size, shown in decimal or hexadecimal; a too-large hexadecimal number becomes the largest allowed and non-numbers change nothing. Leaving keeps the old data.

Stated by the code

3. Store the change

Replaces the data, keeping name and kind, and keeps the value selected.

Inferred from the code
