The chosen system

One deployable on the person's Windows machine, a module per domain: A single server-rendered application holds every domain as an internal module with its own data and rules, talking to one another only through the modules' public contracts. It runs on the Windows machine whose policy is edited, as a program the person starts and uses in a browser on that machine, with the preference store beside it..
