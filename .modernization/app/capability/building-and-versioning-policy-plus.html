Building and versioning Policy Plus

Stamp the program with its current Git version when it is built.

Assumptions we made (1)

The build script puts git's text between two quote marks on separate lines of the generated file. We assume the file is still valid code and the version string works.
Why: Lines 5 to 7 write the git text on its own line, so whether the result compiles is not settled by these lines. The committed generated file holds an empty version, so the result of a run is not shown in the code. If we are wrong: The build would fail or embed a wrong version after the script runs.
