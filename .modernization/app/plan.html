How to run this plan

There are three kinds of prompt. Each is copied from a page of this site, pasted into a coding assistant, and run in this order.

  1. Create the epics, one at a time, in this order. Each epic page holds a prompt that creates the epic and every story under it as work items, then records them in the ledger. An epic's page names the epics that must exist first.
