How to run this plan

There are three kinds of prompt. Each is copied from a page of this site, pasted into a coding assistant, and run in this order.

  1. Create the epics, one at a time, in this order. Each epic page holds a prompt that creates the epic and every story under it as work items, then records them in the ledger. An epic's page names the epics that must exist first.
    Set up the codebase→Set up tooling and environment→Set up libraries→Set up testing→Set up knowledge in code→Build the shared rules→Carry over building and versioning Policy Plus→Carry over getting Microsoft policy definitions→Carry over using the product→Carry over choosing and saving policy sources→Carry over changing policy settings→Carry over finding policies→Carry over editing policy files directly→Carry over browsing policy definitions
  2. Scaffold the codebase. When the epics exist, the prompt on the foundation page makes a branch for the scaffold story and builds the layers, their rules files and their checks. The foundation: layers, decisions and rules files
  3. Deliver the stories, in sequence. Each story page holds a prompt that makes a branch for the story and builds it. A story is delivered only when every story it waits for has been merged. The first story: Set up the codebase and its layers.
