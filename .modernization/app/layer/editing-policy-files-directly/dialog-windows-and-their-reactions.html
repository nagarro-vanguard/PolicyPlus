Business rules (72)

  • In the section dialog, OK does nothing until User or Computer is chosen; then it returns that section and closes.
    On OpenSection · Used by 1 action
  • A number entered for a registry value is limited to 0 to 4,294,967,295 for a 32-bit value and to 0 to 18,446,744,073,709,551,615 for a 64-bit value.
    On EditPol · Used by 2 actions
  • The registry prefix box in the export dialog starts as HKEY_CURRENT_USER\ when the user policy source is being edited and HKEY_LOCAL_MACHINE\ otherwise. It can be changed, and the export uses the text in the box unchecked.
    On EditPol, Main · Used by 2 actions
  • The new registry value dialog offers the types String, Expandable string, List of strings, 32-bit DWord and 64-bit QWord, and starts on String. Confirming returns the typed name, unchecked and possibly empty, with the chosen type; cancelling returns neither.
    On EditPol · Used by 1 action
  • When a REG file is chosen and the prefix is empty, the prefix is guessed from the file; if the file holds default values, the person is warned "This REG file contains data for default values, which cannot be applied to all policy sources."
    On ImportReg · Used by 1 action
  • Only files of type *.reg are offered by the file chooser when browsing for the REG file.
    On ImportReg · Used by 1 action
  • Pressing Escape closes the section dialog as cancelled.
    On OpenSection · Used by 1 action
  • The raw policy file editor lists keys in alphabetical order ignoring case, each followed by its sub-keys indented, then its values in alphabetical order; a value with an empty name (the marker that keeps an empty key) is not listed.
    On EditPol, Main · Used by 7 actions
  • When Delete is confirmed with the option to clear the key or to delete all values under it, the choice is accepted without further input; no option is chosen when the dialog opens, and confirming with none chosen does nothing.
    On EditPolDelete · Used by 1 action
  • When the key name dialog is confirmed, the typed name is returned unchecked; when it is cancelled, an empty name is returned, so an empty typed name and a cancel look the same to the caller.
    On EditPol · Used by 1 action
  • When Delete is confirmed with the option to delete one value and the value name is empty, it is refused and the person is told "You must enter a value name."; with a name, the choice is accepted.
    On EditPolDelete · Used by 1 action
  • The section dialog lets a person choose only the sections the caller allows: User and Computer are each usable only when enabled by the caller.
    On Main · Used by 5 actions
  • When the guess fails, the person is only warned "An error occurred while trying to guess the prefix." and the prefix stays empty.
    On ImportReg · Used by 1 action
  • Export to a registry script is refused until a file name is given; the person is told "Please specify a filename and path for the exported REG."
    On ExportReg · Used by 1 action
  • The value name box in the delete dialog can be typed in only while the option to delete one value is chosen.
    On EditPolDelete · Used by 1 action
  • Pressing Escape closes Import REG as cancelled.
    On ImportReg · Used by 1 action
  • When the registry script is written, the person is told "REG exported successfully." and the dialog closes; on any failure they are told only "Failed to export REG!" and the dialog stays open.
    On ExportReg · Used by 1 action
  • Special deletion entries in a policy file are listed as such: "**deletevalues" as "Delete values" with its data, "**del.<name>" as "Delete value" with the name, and entries starting "**delvals" as "Delete all values". They cannot be edited or deleted.
    On EditPol, Main · Used by 7 actions
  • Import is refused with "Please specify a REG file to import." when no file is named, and with "Please specify the prefix used to fully qualify paths in the REG file." when no prefix is given.
    On ImportReg · Used by 1 action
  • Import loads the REG file with the prefix and applies it straight to the chosen policy source; on any failure the person is told only "Failed to import the REG file."
    On ImportReg · Used by 1 action
  • When a typed hexadecimal number is too large to fit, the value is set to the largest allowed value; text that is not a hexadecimal number leaves the value unchanged.
    On WideRangeNumericUpDown · Used by 2 actions
  • Ordinary values are listed with their content: lists of text joined by spaces, text as it is, 32-bit and 64-bit numbers in decimal, binary data as hexadecimal bytes separated by spaces. Other kinds show no content.
    On EditPol, Main · Used by 7 actions
  • Pressing Done (or Enter) closes the raw policy editor as accepted, and pressing Escape closes it as cancelled; there is no Cancel button. The caller ignores the answer, so every change made in the editor stays on the loaded policy source either way, to reach disk only when policies are saved.
    On EditPol · Used by 1 action
  • A category appears in the tree only when it passes the visibility rule; each shown category gets an icon by its kind and carries its visible subcategories below it, and the tree is sorted.
    On Main · Used by 3 actions

    On EditPol · Used by 1 action

Then, if the policy is in the same category and the list still has that many rows, the earlier top row is put back, so the policy is not guaranteed to stay in view.
    On Main · Used by 3 actions
  • A new key name is refused with "The key name is already taken." when a key of that name, ignoring case, already exists under the same parent.
    On EditPol · Used by 1 action
  • Adding a key does nothing when the name is left empty or the dialog is cancelled; otherwise the key is created under the selected key, or at the top level when nothing is selected, as an empty key, and is selected in the list.
    On EditPol · Used by 1 action

    On Main · Used by 3 actions

Any other kind, such as binary, is refused with "This value kind is not supported." and nothing changes. Cancelling the dialog leaves the value as it was.
    On EditPol · Used by 2 actions
  • The category tree selection follows the category shown in the right pane.

    On EditPol · Used by 1 action

Clear first marks the key cleared and puts back only its existing direct values with ordinary content; deletion entries already in that key are lost and values of sub-keys are not put back. Delete one value is refused with "You must enter a value name." when the name is empty; otherwise any value of that name, whether or not it exists, is removed and replaced by a deletion entry.
    On EditPol · Used by 1 action
  • A category's icon is chosen in this order: orphaned, then empty, then normal.

  • A policy's icon is chosen in this order: preference, then plain when it has no configurable elements, then "extra configuration" when it has some.

    On Main · Used by 3 actions

Forgetting a value removes the value and its deletion entry the same way.
