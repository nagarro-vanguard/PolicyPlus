Program setup and settings

Settings that tell Windows how to run the program and the helper that keeps the person's choices between runs. In Using the product: 0 actions and 1 business rule. Part of its code is also used by other capabilities.

What can be started here (0)

Nothing starts in this layer; work reaches it from other layers.

Business rules in this layer (1)

When the program's settings area in the registry cannot be opened or created, the program carries on without it: settings read as their defaults, changes are dropped, and the person is not told, so settings are not remembered between runs.
