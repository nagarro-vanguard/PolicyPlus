Build tooling

Scripts a developer runs outside the program to prepare it for compiling, such as stamping the build with its version.

  • 1 action started here
  • 1 business rule

Used in journeysMake each built copy of the program carry

Actions started here (1)

  • Rewrites the generated version file so the program carries the current Git commit description.

Business rules (1)

  • When the build script runs, it replaces the program's version in a generated source file with the text git gives for the current commit. That text is a tag, commit count and short commit name when tags exist, and a short commit name otherwise. The script runs when someone runs it or the release workflow does. The committed file holds an empty version.
