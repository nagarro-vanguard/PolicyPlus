For an administrator, each folder handed to the file move that already exists, the destination itself and any existing language folder, has its ownership taken; a language folder created during the move instead inherits permissions from the folder above. A failure here ends the download with "Failed to move the ADMX files.", not the take-control message.

The template files are moved into the destination, then the language files for the person's regional format language (the culture of the regional settings, which can differ from the display language) are moved into a folder of that name if the package holds one. If only the final cleanup of the scratch folder fails, all files are already installed yet the person is told "Failed to remove temporary files." and no new policy folder is offered.
