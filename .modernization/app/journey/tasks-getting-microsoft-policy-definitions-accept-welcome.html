Be offered the full set of policy definitions

Be offered the full set of policy definitions the first time the program is used on an edition that lacks them.

Why this way recommended

On first use the system works out whether definitions are lacking and makes a single offer, and if it is passed over the invitation stays quietly available.

The person is never lost if they decline once, the offer is still made only once, and the lack of definitions is worked out without asking.

Trade-off: Needs a standing invitation, which is more to design than a one-time question.

The architecture, modernized

Rules kept and dropped: 5 kept, 0 dropped
  • The welcome offer to download policy definitions is considered only once: the first time the window is shown the program records that it has been considered, even when no offer is made, and never considers it again.
  • The computer counts as having the Group Policy infrastructure only when the number Windows gives for its edition equals one of 59 fixed codes in a list.
  • A category is orphaned when it has no parent among the loaded definitions although its definition names one.
  • A category is empty when it holds no subcategories and no policies at all, counting hidden ones.
  • When the offer is considered, it is made only if this Windows edition has no Group Policy support and more than two non-empty categories name a parent that is not among the loaded definitions.
