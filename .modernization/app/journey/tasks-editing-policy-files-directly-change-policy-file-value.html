2Enter the new data

Takes text, a list of lines, or a number within the limits of its size, shown in decimal or hexadecimal; a too-large hexadecimal number becomes the largest allowed and non-numbers change nothing. Leaving keeps the old data.

inferredLet the system read the number, then keep the changeInferred

The person no longer has to know which mode is on, and reading and saving become one step.

Why this way recommended

The system accepts a number in decimal or hexadecimal as typed and shows both forms, so there is no mode to switch.

Removes the mode switch while keeping every rule about size and unreadable input.

Trade-off: Guessing the form from the text can be ambiguous for digits-only input, so a clear prefix is required for hexadecimal.

The architecture, modernized

Rules kept and dropped: 2 kept, 0 dropped
  • When a typed hexadecimal number is too large to fit, the value is set to the largest allowed value; text that is not a hexadecimal number leaves the value unchanged.
  • Editing a value replaces its data with the confirmed new data and keeps its name and kind; the value stays selected.
Other ways considered: 2
  • Edit in place by kind 4 steps. The person selects a value, enters new data in the form that fits its kind, and chooses decimal or hexadecimal for numbers. Trade-off: The decimal or hexadecimal choice is still a separate decision.
  • Preview then confirm 3 steps. The person is shown what the value will become, with its kind and limits explained, and confirms. Trade-off: An extra confirmation for a small change.
Evidence from the code: 7 actions, 2 rules
  • Asks for new data for the selected value and stores it in the policy file.
  • Closes the string dialog as cancelled when Escape is pressed.
  • Closes the list-of-strings dialog as cancelled when Escape is pressed.
  • Switches the number box between decimal and hexadecimal display.
  • Closes the number dialog as cancelled when Escape is pressed.
  • Shows the value as hexadecimal text when hexadecimal mode is on, otherwise leaves display to the standard control.
  • Reads typed hexadecimal text into the value in hexadecimal mode, otherwise leaves it to the standard control.
