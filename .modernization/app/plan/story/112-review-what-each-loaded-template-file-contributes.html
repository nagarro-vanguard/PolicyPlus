Review what each loaded template file contributes

What it delivers

A person sees the policy template files loaded in the workspace with a summary of what each one defines, and can open one file to see exactly what it defines.

Why

So a person can tell which template files are in use and what each adds, without opening every file to find out.

Waits for these stories to be merged

Nothing: it can start as soon as it is created.

Builds 1 rule of the existing system.

Acceptance criteria (1)

  1. Given a file's details are open, when a person reads them, then they list only the policies, categories (including sub-categories), products (including versions) and support rules that were defined in that file.

Terms it introduces

Loaded template file
A policy template file that has been read into the workspace and whose definitions are in use; not a file that is merely present in a folder.
File contribution
The policies, categories, products and support rules that one template file defines; not what other loaded files define.
