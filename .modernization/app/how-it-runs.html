How is one piece of work carried out, from arrival to response?
The person picks a setting and a dialog edits it in memory. When the source is the live local registry, each change is written to the registry at once, and Save reports it as already applied. File and per-user profile sources wait for Save, or for the source to close. Save writes comments, then both stores, then remembered sources. Language and definitions folder are saved when chosen. The definition download and the Find results search run in background tasks.

Which rules does it apply?
Loading policy templates applies two loose rules. It uses the exact language folder, else the first folder of the same primary language that holds the language file, else en-US; with none, the file is refused. It never checks the language file against the template's minimum revision, so an outdated file loads silently.
