Dialog windows and their reactions
Forgetting a key asks "Are you sure you want to remove this key and all its contents?" and, on Yes, removes the key, all its sub-keys, every value and every clearing mark from the file with no deletion left behind; No changes nothing. Forgetting a value removes the value and its deletion entry the same way.

Special deletion entries in a policy file are listed as such: "**deletevalues" as "Delete values" with its data, "**del.<name>" as "Delete value" with the name, and entries starting "**delvals" as "Delete all values". They cannot be edited or deleted.

Policy definitions and files
When a policy file is clearing a key, all values and markers under the key are dropped and a single clear-all marker is stored.
PolicyPlus/PolicySource.vb:183 · Screens: EditPol, ExportReg, ImportReg, Main
A value in a policy file counts as marked for deletion when a deletion marker names it, when the key has a clear-all marker, or when a delete-values list for the key names it, regardless of case. Entries are examined in sorted order, and a value whose name sorts after the marker is stored as present and cancels the deletion, whenever it was written and whichever marker kind came before.
