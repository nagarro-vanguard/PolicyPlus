Business rules along the way (4)

Dialog windows and their reactions
When OK is pressed, the user source is created from the selected choice: Local GPO, Registry, POL file, per-user GPO (SID typed), user hive (file path typed), or Scratch space otherwise. If it cannot be created, the person is told "The user policy loader could not be created." followed by the reason, and the dialog stays open; the dialog closes as accepted only when both sources were created.
PolicyPlus/OpenPol.vb:92 · Screens: OpenPol
When OK is pressed, the computer source is created from the selected choice: Local GPO, Registry (path typed), POL file (name typed), or Scratch space when none of the others is selected. If it cannot be created, the person is told "The computer policy loader could not be created." followed by the reason, and the dialog stays open.

Policy definitions and files
A registry source must start with HKCU, HKEY_CURRENT_USER, HKU, HKEY_USERS, HKLM or HKEY_LOCAL_MACHINE (any case); otherwise it is refused with "The root key is not valid." A path after the root is opened, and created if missing.
PolicyPlus/PolicyLoader.vb:20 · Screens: OpenPol
The path of a policy source is fixed by its kind: Local GPO uses the Registry.pol file of the system's local Group Policy (user or machine folder) and its gpt.ini; a per-user GPO uses the folder named by the person's SID under GroupPolicyUsers; a POL file and a user hive use the path given; Scratch space has none.
