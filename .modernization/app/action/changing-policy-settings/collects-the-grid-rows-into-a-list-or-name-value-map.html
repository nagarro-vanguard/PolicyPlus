Dialog windows and their reactions
When the list editor is confirmed for a list where the person names each entry, and two entries have exactly the same name, it is refused with "Multiple entries are named "<name>"! Remove or rename all but one." and nothing is returned. Names are compared exactly, so Run and run are accepted as two entries. A name cell never filled in stops the dialog with an unhandled error.
