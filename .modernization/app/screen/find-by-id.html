PolicyPlus/Main.Designer.vb:266
The area choice offers only "User or Computer", "User" and "Computer", with no free text.
PolicyPlus/Main.Designer.vb:409
Only one item in the policy list can be selected at a time.
PolicyPlus/Main.Designer.vb:534
Text typed in Find by ID is trimmed and looked up in this order: category, product, support definition, then policy. The first kind that matches is selected, with its own icon shown; a policy is looked up only when no other kind matches.
PolicyPlus/FindById.vb:22
When the text matches nothing, nothing is selected and a "not found" icon is shown; when the text is empty a blank icon is shown instead. The section from an earlier match is not cleared when the text changes to a non-policy.
PolicyPlus/FindById.vb:24
A policy ID may end with "@U" to mean the user section or "@C" to mean the computer section; without a suffix, or with any other suffix, the policy applies to both sections. The suffix is cut off before the policy lookup, so an unknown suffix still finds the policy.
PolicyPlus/FindById.vb:39
Go closes Find by ID as accepted whether or not the text matched anything, so the caller may receive no selection.
PolicyPlus/FindById.vb:59
Pressing Escape closes Find by ID as cancelled.
