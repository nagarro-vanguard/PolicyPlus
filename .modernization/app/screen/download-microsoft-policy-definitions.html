Download Microsoft policy definitions

Choose a folder and download Microsoft's current policy templates into it. Built from PolicyPlus/DownloadAdmx.vb

Risks 16 risks in this code

  • Medium For an administrator, the program unpacks a package it never verified and then makes Administrators owner of the typed destination with full control, so a compromised source would be trusted with that folder.
  • Medium Results of requesting Windows privileges and loading a user registry file are discarded. The person learns a source cannot be saved, or silently gets an empty read-only source, never why. A refused privilege passes silently and fails later with an unrelated error.
  • Medium The download accepts what it is given without checks: the package is unpacked with no signature or hash check, and the destination is any folder typed. For an administrator the files written also get their access rules reset. The package address is fixed HTTPS, so the package gap matters only if that channel is compromised.
  • Medium The download destination is free text and never checked as a policy definitions folder. A wrong existing folder typed or browsed to, which needs an administrator to change the default, has its ownership taken and its same-named files deleted and replaced. A folder that does not exist is simply created.

  • Medium The downloaded Microsoft template package is run through the Windows installer tool with no signature, publisher or hash check, only a secure address. The tool processes the package before anything is verified, so a compromised channel or address delivers altered files for the template folder.
  • Medium The Microsoft template package is unpacked with no hash or signature check, so a tampered or substituted package would have its files moved into the policy template folder. The address is a fixed Microsoft link, which limits exposure to a compromised source or channel.
  • Medium The program allows TLS 1.0 and 1.1 as well as 1.2 for every web request, which is only the template download, to keep Vista working. A server or on-path party forcing an old protocol would be accepted. The download address is fixed HTTPS.
  • Medium The template download deletes each existing file before moving the new one in. A failure midway leaves the destination partly replaced, and the scratch folder with the downloaded package stays in the person's local data. Only the failed step is reported.
  • Medium The template download, run as administrator, takes ownership of the destination folder and its existing language subfolders, grants Administrators full control and replaces same-named files; a missing folder is created. This happens to the system definitions folder even on the default path, not only when another folder is typed.
  • Medium The template download, when run as administrator, takes ownership of whatever folder is typed or browsed to, grants Administrators full control, and deletes and replaces same-named files there. The folder defaults to the standard template folder but is not checked, so a wrong existing folder has its ownership and permissions changed.
  • Medium What the template download moves into the policy template folder is whatever the unpacked package holds. With no check of the package, a tampered or substituted one replaces the installed templates, which the program then loads as trusted definitions.
  • Medium When a download, install or export fails, the person sees only the step that failed, not the cause, with no retry. A finished install can be reported as a failure when cleanup fails, leaving the new folder unloaded and unpacked files behind.
  • Medium When rights or a per-user registry file cannot be obtained, the results are discarded. The person is told a source cannot be modified or saved, never why, and can keep editing an empty in-memory source that is never written.
  • Low The program permits TLS 1.0 and 1.1 alongside 1.2 for every web request it makes, which is only the template download; a comment gives Vista compatibility as the reason. A connection uses the best version both ends offer, but a server or on-path party forcing an old version would be accepted.
  • Low The template download uses one fixed address naming a single dated Windows 11 package (26H2) and its folder layout, with no fallback. When Microsoft retires it, or a newer release appears, the feature fails until the program is rebuilt.
  • Low When a download, unpack or move fails, the person sees only which step failed, not the cause. The scratch folder is removed only on success, and files already moved into the destination are not rolled back.

Dialog windows and their reactions (12)

PolicyPlus/DownloadAdmx.vb:7
When the person closes the download window while a download is running, the close is refused; the window closes only when no download is running.
PolicyPlus/DownloadAdmx.vb:14
While a download runs, the start button, close button, destination box and browse button are all disabled, so a second download cannot be started and the destination cannot change; they are enabled again when it ends.
PolicyPlus/DownloadAdmx.vb:22
Each time the download window opens, the destination folder is set to the Windows policy definitions folder (the PolicyDefinitions folder under the Windows folder) and no new policy folder is reported to the caller.
PolicyPlus/DownloadAdmx.vb:17
Before any file is moved, when the folder written in the destination box already exists and the person is an administrator, ownership of it is taken and Administrators are given full control. This applies to whatever folder text is in the box, not only the Windows folder; a standard user skips it. A failure ends the download with "Failed to take control of the destination." and nothing is moved.
PolicyPlus/DownloadAdmx.vb:94
Changes a state
When any step fails, the person is told "Failed to " followed by the step that failed (create a scratch space, download the package, extract the package, take control of the destination, move the ADMX files, remove temporary files); the window stays open, controls are re-enabled, and no policy folder is reported. If only the final cleanup of the scratch folder fails, all files are already installed yet the person is told "Failed to remove temporary files." and no new policy folder is offered.
PolicyPlus/DownloadAdmx.vb:125
The template files are moved into the destination, then the language files for the person's regional format language (the culture of the regional settings, which can differ from the display language) are moved into a folder of that name if the package holds one. Unless that language is en-US, the English files are also moved into an en-US folder as a fallback; if the package has no en-US folder, the download stops with "Failed to move the ADMX files." after the destination files were already replaced.
PolicyPlus/DownloadAdmx.vb:103
Changes a state
When files are moved into a folder, the folder is created if missing and every file already there with the same name is deleted first and then replaced by the new one, with no backup. Only files directly in the source folder are moved. A failure part-way leaves some files replaced and others not.

Starting the download always fetches one fixed Microsoft package, the Windows 11 September 2026 Update (26H2) administrative templates, into a scratch folder under the person's local application data as "W11Admx.msi"; the person cannot choose another version.
PolicyPlus/DownloadAdmx.vb:83
Changes a state
For an administrator, each folder handed to the file move that already exists, the destination itself and any existing language folder, has its ownership taken; a language folder created during the move instead inherits permissions from the folder above. Every moved file, including the template files in the destination, is reset to inherit permissions. A standard user changes no permissions. A failure here ends the download with "Failed to move the ADMX files.", not the take-control message.
