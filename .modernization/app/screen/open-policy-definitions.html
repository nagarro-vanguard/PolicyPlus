Open policy definitions

Choose the folder, Windows or domain location to load definitions from. Built from PolicyPlus/OpenAdmxFolder.vb

Risks 2 risks in this code

  • Medium Policy template and comment XML files are read with default settings and no stated limit on external references. The folders or domain share they come from may be writable by others, and whether external entities resolve depends on the framework default.
  • Medium Template and comment XML files, read from a chosen folder or the domain share, are loaded with default settings and no stated limit on external references. Whether those resolve rests on the framework default, which the code does not settle. If they do, a crafted file on a writable share could read local files.
