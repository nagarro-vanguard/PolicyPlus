Business rules for this screen (6)

Dialog windows and their reactions (6)
Search text is split at spaces into plain words, wildcard words (containing "*" or "?") and quoted phrases. Words are lowercased and trimmed and lose the characters . , ' " ; / ! ( ) { } [ ].
PolicyPlus/FindByText.vb:25
A text is a hit only when it contains every plain word as a whole word, every wildcard matching some word, and every quoted phrase as whole words together.
PolicyPlus/FindByText.vb:51
When none of In title, In description and In comment is ticked, the search is refused with "At least one attribute must be searched. Check one of the boxes and try again."; all three start ticked.
PolicyPlus/FindByText.vb:17
A policy matches when the ticked attributes hit: its title, its description, or a comment on it from any supplied comment source (user or computer). Any one hit is enough.
PolicyPlus/FindByText.vb:59
A phrase opened with a double quote runs until a later word ending in a double quote; a phrase never closed is dropped without telling the person, which widens the search. A single quoted word such as "abc" does not close itself, so it also absorbs the following words.
PolicyPlus/FindByText.vb:36
When Search is pressed with the search text empty, the search is refused and the person is told "Please enter search terms."
PolicyPlus/FindByText.vb:12
