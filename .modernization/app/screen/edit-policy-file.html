Edit policy file

Browse a policy file and, in steps, add keys and values, edit text, number and list values, or choose what to delete. Built from PolicyPlus/EditPol.vb, PolicyPlus/EditPolDelete.vb, PolicyPlus/EditPolKey.vb, PolicyPlus/EditPolMultiStringData.vb, PolicyPlus/EditPolNumericData.vb, PolicyPlus/EditPolStringData.vb, PolicyPlus/EditPolValue.vb

Risks 2 risks in this code

  • Medium The name of a value added in the raw policy editor is not checked. An empty name hides the key's marker, and names that begin with deletion prefixes or equal the delete-values name are read back as deletion or clearing instructions.
  • Low Escape in the raw policy editor looks like a cancel, but every edit has already changed the loaded policy source and the caller ignores the answer. Changes cannot be discarded except by not saving afterwards.

Policy definitions and files (17)
A value in a policy file counts as marked for deletion when a deletion marker names it, when the key has a clear-all marker, or when a delete-values list for the key names it, regardless of case. Entries are examined in sorted order, and a value whose name sorts after the marker is stored as present and cancels the deletion, whenever it was written and whichever marker kind came before.
PolicyPlus/PolicySource.vb:118
Listing the values of a key in a policy file leaves out the marker entries unless the caller asks for them.
PolicyPlus/PolicySource.vb:139
Reading a value from a policy file gives nothing when the value is absent or marked for deletion.
PolicyPlus/PolicySource.vb:114
A value in a policy file counts as present only if it is stored and not marked for deletion.
PolicyPlus/PolicySource.vb:110
A multiple-string value is stored as its strings each followed by an empty character, with one more empty character closing the list.
PolicyPlus/PolicySource.vb:296
A 64-bit number is stored in a policy file as 8 bytes, lowest byte first.
PolicyPlus/PolicySource.vb:272
A key name in a policy file is listed as a subkey only once, regardless of case, and the requested key itself is never listed.
PolicyPlus/PolicySource.vb:196
Text read from a policy file stops at its first empty character, and a multiple-string value ends at its first empty string.

PolicyPlus/PolicySource.vb:337
When a policy file is clearing a key, all values and markers under the key are dropped and a single clear-all marker is stored.
PolicyPlus/PolicySource.vb:183
When a value is forgotten in a policy file, both the value and its deletion marker are removed, so the policy reverts to not saying anything about it.
PolicyPlus/PolicySource.vb:99
When a key's clearance is forgotten in a policy file, every clear-all marker for that key is removed.
PolicyPlus/PolicySource.vb:190
When a value is marked for deletion in a policy file, any value or marker already held under that name is dropped first. A deletion marker holding the number 32, as Microsoft does, is added unless the value is already marked or its key is cleared.
