Business rules for this screen (10)

Dialog windows and their reactions (10)
When a policy sits in a category that exists, the category name is shown and the category-details button is enabled. A policy whose named category is unknown shows "<orphaned from " followed by that category code, and one with no category code shows "<uncategorized>"; the button is then disabled.
PolicyPlus/DetailPolicy.vb:27
When a policy names a support definition that exists, its name is shown and the support-details button is enabled. When it does not exist, the button is disabled and the text reads "<missing: " followed by the code the policy names; with no code the text is blank.
PolicyPlus/DetailPolicy.vb:19
The policy details window names the section a policy applies to: "User or computer" when it applies to both, "Computer" when machine-only, "User" when user-only.
PolicyPlus/DetailPolicy.vb:11
The detail window of a category shows its parent's name and enables the parent button when the parent exists; when the parent is named but missing it shows "<orphaned from <parent>>" and the button is disabled; a top-level category shows nothing.
PolicyPlus/DetailCategory.vb:14
The product details window lists every child revision of a product with its version and name; a product with no children shows an empty list.
PolicyPlus/DetailProduct.vb:29
A product with a parent shows the parent name and enables the parent button; a product with no parent shows a blank parent and the button is disabled.
PolicyPlus/DetailProduct.vb:22
The product details window shows a version number for major and minor revisions only; for a top-level product the version is blank.
PolicyPlus/DetailProduct.vb:21
The product details window labels a product "Major revision", "Minor revision" or "Top-level product" from its type.
PolicyPlus/DetailProduct.vb:13

Each entry of a support definition is listed by the name of the nested support definition when it is one, otherwise by the name of the product, otherwise as "<missing: " followed by the product code the entry names. Minimum and maximum versions are listed only for product entries that name a version range; a missing bound is shown blank.
PolicyPlus/DetailSupport.vb:20
The support details window states how a support definition matches products: "Match all the referenced products", "Match any of the referenced products", or "Do not match products" when it has no matching logic.
