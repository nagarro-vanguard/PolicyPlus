Business rules for this screen (4)

Dialog windows and their reactions (4)
A name typed in the user dialog is turned into the account's security identifier (SID) on Search; if the name cannot be translated, the person is told "The name could not be translated to a SID."
PolicyPlus/OpenUserGpo.vb:4
When OK is pressed, the SID text must be a valid SID or the person is told "The SID is not valid. Enter a SID in the lower box, or enter a username in the top box and press Search to translate."; a valid SID is returned and the dialog closes.
PolicyPlus/OpenUserGpo.vb:20
When OK is pressed with a name typed but no SID, the name is looked up first, and the dialog stays open if no SID results.
PolicyPlus/OpenUserGpo.vb:14
