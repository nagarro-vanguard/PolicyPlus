Choose policy sources

Choose where user and computer policies are read from and saved. Built from PolicyPlus/OpenPol.vb

Risks 2 risks in this code

  • Medium Text typed by the person, a user identifier or a language code, is used unchecked as part of a folder path. Path characters redirect where policy and version files are created or which folder is searched for definition text, using the person's own rights.
  • Low A typed user identifier is joined into the per-user policy folder path with no check, so a crafted value can point the written policy and version files at another folder. It acts only with the person's own rights.

Policy definitions and files (2)
A registry source must start with HKCU, HKEY_CURRENT_USER, HKU, HKEY_USERS, HKLM or HKEY_LOCAL_MACHINE (any case); otherwise it is refused with "The root key is not valid." A path after the root is opened, and created if missing.
PolicyPlus/PolicyLoader.vb:20
The path of a policy source is fixed by its kind: Local GPO uses the Registry.pol file of the system's local Group Policy (user or machine folder) and its gpt.ini; a per-user GPO uses the folder named by the person's SID under GroupPolicyUsers; a POL file and a user hive use the path given; Scratch space has none.
