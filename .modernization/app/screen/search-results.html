Search text is split at spaces into plain words, wildcard words (containing "*" or "?") and quoted phrases. Words are lowercased and trimmed and lose the characters . , ' " ; / ! ( ) { } [ ].

A text is a hit only when it contains every plain word as a whole word, every wildcard matching some word, and every quoted phrase as whole words together.
PolicyPlus/FindByText.vb:51
A value-name term must match the whole value name; "*" and "?" act as wildcards, so without them the name must be equal.
PolicyPlus/FindByRegistry.vb:20
A key term containing a backslash but no wildcard matches policies whose key path starts with that text.

A policy matches when the ticked attributes hit: its title, its description, or a comment on it from any supplied comment source (user or computer). Any one hit is enough.
PolicyPlus/FindByText.vb:59
A key term containing "*" or "?" must match the whole key path as a wildcard pattern.
PolicyPlus/FindByRegistry.vb:24
A policy matches a registry search when at least one registry value it reads or writes meets every term entered; matching ignores case.

PolicyPlus/PolicySource.vb:183
A REG file cannot be used as a source for forgetting a value: the request fails with 'not implemented'. Applying a newer policy file over an older one to a REG file fails this way for any dropped value under a policy branch.
PolicyPlus/RegFile.vb:237
Listing the values of a key in a policy file leaves out the marker entries unless the caller asks for them.
PolicyPlus/PolicySource.vb:139
When a policy is forgotten, the whole key of each of its list elements is cleared and every registry value it touches is dropped from the source, so it reads as Not configured.
PolicyPlus/PolicyProcessing.vb:249
In the live registry, 'forgetting' a value deletes it, because the registry cannot remember a pending deletion.
PolicyPlus/PolicySource.vb:371
When a value is forgotten in a policy file, both the value and its deletion marker are removed, so the policy reverts to not saying anything about it.
PolicyPlus/PolicySource.vb:99
Clearing a key in the live registry deletes every value in it but leaves the key and its subkeys. Forgetting a key's clearance does nothing.
PolicyPlus/PolicySource.vb:416
When a key's clearance is forgotten in a REG file, the key-removal entry is dropped if it exists. The request is ignored if a source branch is set and the key lies outside it. When no branch is set, every key is accepted.
