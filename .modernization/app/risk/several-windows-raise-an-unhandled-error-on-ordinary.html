Overview › What can go wrong › Low

Several windows raise an unhandled error on ordinary input: double-clicking with no row selected, right-clicking with no category, an unnamed list entry, an unreadable import file, a malformed search wildcard, a removed product in a filter, or an inspector item with no match. No program-wide handler is set, so the framework's default error dialog appears.

Severity: Low. Kind of risk: Failures are hidden, lost or not retried.
