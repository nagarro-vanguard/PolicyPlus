Overview › What can go wrong › Medium

Comment loading and saving failures are hidden. An unreadable comment file silently disables comments for that source, a failed save is dropped so typed comments are lost, and turning on the comment filter then fails with an unhandled error.

Severity: Medium. Kind of risk: Failures are hidden, lost or not retried.
