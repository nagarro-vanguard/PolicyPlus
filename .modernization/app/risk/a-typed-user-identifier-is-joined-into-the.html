Overview / What can go wrong

A typed user identifier is joined into the per-user policy folder path with no check, so a crafted value can point the written policy and version files at another folder.

  • Input from outside is used without checks, so it can change what the code does
  • Low

Why it matters

It acts only with the person's own rights.

What we found

  • A typed user identifier is joined into the path of the per-user policy folder with no check. Path separators or dots are not rejected, so a crafted value can point the written policy and version files at another folder, using the person's own rights.
