Overview › What can go wrong › Medium

The template download, run as administrator, takes ownership of the destination folder and its existing language subfolders, grants Administrators full control and replaces same-named files; a missing folder is created. This happens to the system definitions folder even on the default path, not only when another folder is typed.

Severity: Medium. Kind of risk: Someone can read or change what they should not.
