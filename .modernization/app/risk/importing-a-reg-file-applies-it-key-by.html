Overview › What can go wrong › Medium

Importing a REG file applies it key by key to the live policy source with no rollback, and a REG source cannot read or forget values. A failure leaves earlier changes in place and the person sees only a general failure message.

Severity: Medium. Kind of risk: Data can end up wrong, lost or inconsistent.
