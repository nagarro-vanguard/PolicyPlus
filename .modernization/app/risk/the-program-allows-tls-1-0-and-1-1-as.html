Overview / What can go wrong

The program allows TLS 1.0 and 1.1 as well as 1.2 for every web request, which is only the template download, to keep Vista working.

  • Data is protected by weak or fixed encryption
  • Medium

Why it matters

A server or on-path party forcing an old protocol would be accepted. The download address is fixed HTTPS.

What we found

  • The program sets TLS 1.0, 1.1 and 1.2 for the whole process; a code comment gives Vista compatibility as the reason. The framework target is 4.5.2, where TLS 1.2 is not the default and must be set explicitly. The only request seen is the download from a fixed HTTPS address; a downgrade needs the server or an on-path party to offer the old protocol.
    Technology: Windows Forms
  • The program allows TLS 1.0, 1.1 and 1.2 together for every web request the process makes, so a download uses the newest version both sides support. Older versions stay permitted. A code comment says this keeps Vista working.
    Technology: Microsoft Windows
  • The program sets older TLS versions 1.0 and 1.1 alongside 1.2 for every web request it makes, which is the single definition download. The connection normally uses the best version both ends support, but a server or middlebox forcing an older version would be accepted. A comment ties it to Vista.
    Part: Policy Plus desktop editor
  • The program allows TLS 1.0 and 1.1 as well as 1.2 for every web request, kept for Vista compatibility, so the definition files can be downloaded over protocols known to be weak.
    Capability: Getting Microsoft policy definitions
