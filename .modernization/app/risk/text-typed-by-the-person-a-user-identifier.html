Overview › What can go wrong › Medium

Text typed by the person, a user identifier or a language code, is used unchecked as part of a folder path. Path characters redirect where policy and version files are created or which folder is searched for definition text, using the person's own rights.

Severity: Medium. Kind of risk: Input from outside is used without checks, so it can change what the code does.

What the code shows (3)

A typed user identifier is joined into the path of the per-user policy folder with no check. Path separators or dots are not rejected, so a crafted value can point the written policy and version files at another folder, using the person's own rights.
Technology: Microsoft Windows
