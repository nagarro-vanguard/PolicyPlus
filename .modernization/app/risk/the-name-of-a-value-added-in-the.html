Overview › What can go wrong › Medium

The name of a value added in the raw policy editor is not checked. An empty name hides the key's marker, and names that begin with deletion prefixes or equal the delete-values name are read back as deletion or clearing instructions.

Severity: Medium. Kind of risk: Input from outside is used without checks, so it can change what the code does.

What the code shows (1)

The name of a value added in the raw policy editor is not checked. It can be empty, which overwrites the key's empty-key marker and hides it from the list, or begin with the deletion prefixes or equal the delete-values name, so an ordinary value is stored that is read back as a deletion or clearing instruction.
