Overview › What can go wrong › Medium

Results of requesting Windows privileges and loading a user registry file are discarded. The person learns a source cannot be saved, or silently gets an empty read-only source, never why. A refused privilege passes silently and fails later with an unrelated error.

Severity: Medium. Kind of risk: Failures are hidden, lost or not retried.

What the code shows (4)

When rights or a registry hive cannot be obtained, the results of the privilege calls, the hive load and the settings key opening are discarded. The person is told a source cannot be modified or saved, but never why. The download path likewise ignores the privilege result.
