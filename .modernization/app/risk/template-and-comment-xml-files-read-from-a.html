Overview › What can go wrong › Medium

Template and comment XML files, read from a chosen folder or the domain share, are loaded with default settings and no stated limit on external references. Whether those resolve rests on the framework default, which the code does not settle. If they do, a crafted file on a writable share could read local files.

Severity: Medium. Kind of risk: Input from outside is used without checks, so it can change what the code does.
