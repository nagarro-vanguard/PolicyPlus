Overview › What can go wrong › Medium

For an administrator, the program unpacks a package it never verified and then makes Administrators owner of the typed destination with full control, so a compromised source would be trusted with that folder.

Severity: Medium. Kind of risk: Releasing or running the system depends on manual or missing steps.

What the code shows (1)

The definition package is downloaded from a Microsoft address, unpacked and its files moved into the chosen folder with no signature or checksum check, so a compromised source would be trusted. When run as administrator, the program then enables ownership and restore privileges, makes Administrators owner of the destination, and grants full control. The destination is whatever is typed.
