Overview › What can go wrong › Medium

The download destination is free text and never checked as a policy definitions folder. A wrong existing folder typed or browsed to, which needs an administrator to change the default, has its ownership taken and its same-named files deleted and replaced. A folder that does not exist is simply created.

Severity: Medium. Kind of risk: Input from outside is used without checks, so it can change what the code does.

What the code shows (2)

The download dialog accepts any folder the person types or browses to, without checking it. When run as administrator it takes ownership of an existing folder, grants Administrators full control, and deletes and replaces same-named files. Pointed at the wrong folder, it changes ownership and permissions there.
