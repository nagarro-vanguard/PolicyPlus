Overview › What can go wrong › Medium

Importing a REG file applies it to whichever source is open, live registry or policy file, with no check of the keys it names. The branch limit exists only when a REG file is the target, so an import can write, delete or clear keys outside the policy branches.

Severity: Medium. Kind of risk: Someone can read or change what they should not.

What the code shows (1)

Imported REG files are applied without the source-branch limit that the same class enforces when saving, so a REG file can write, delete or clear keys anywhere under its prefix.
