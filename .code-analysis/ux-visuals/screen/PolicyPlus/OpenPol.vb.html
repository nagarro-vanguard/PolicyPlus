Policy state logic and Windows interop (2)
A registry policy source accepts the root key names hkcu, hkey_current_user, hku, hkey_users, hklm and hkey_local_machine in any letter case; any other root is refused with "The root key is not valid." A path after the root is created if missing.
PolicyPlus/PolicyLoader.vb:21
The local policy source uses the Machine or User Registry.pol under the Windows GroupPolicy folder and its gpt.ini; a per-user policy source uses GroupPolicyUsers\<SID>\User\Registry.pol and that folder's gpt.ini.
