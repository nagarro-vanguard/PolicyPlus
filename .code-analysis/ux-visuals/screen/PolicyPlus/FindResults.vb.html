The search task in the results dialog has no handling for an error raised by the search function, so an invalid pattern in Find by Registry ends the task without a finishing message or any change to the dialog.

A search starts only when the dialog appears after a search request; reopening it instead reselects the last chosen result if it is still in the list.

When the dialog is closed during a search, no further results or status are written, and the label reads 'Search canceled'.
PolicyPlus/FindResults.vb:82
A finished search reports 'Finished searching: checked N policies, found M hits' and a stopped one 'Search canceled: checked N policies, found M hits'; Stop is then disabled and progress shows full. Mid-search it shows 'Searching: checked N policies so far, found M hits'.
