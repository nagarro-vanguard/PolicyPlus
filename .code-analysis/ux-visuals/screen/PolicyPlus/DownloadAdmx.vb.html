PolicyPlus/DownloadAdmx.vb:22
Each time the download dialog opens, the destination defaults to the Windows PolicyDefinitions folder, the "open after download" folder is cleared and the dialog is idle.
PolicyPlus/DownloadAdmx.vb:17
If any step fails, the download stops, the dialog becomes idle again and the person is told "Failed to " followed by the step that failed ("create a scratch space", "download the package", "extract the package", "take control of the destination", "move the ADMX files" or "remove temporary files"), ending with a period. Nothing is rolled back: files already moved into the destination stay, and the scratch folder is deleted only as the last step, so an earlier failure leaves it behind. A failure at "remove temporary files" comes after the files were installed.
PolicyPlus/DownloadAdmx.vb:76
The destination text is not checked before the download starts: empty or invalid text is passed on and the download fails at "move the ADMX files". A person who is not a Windows administrator skips the ownership step and proceeds, so a protected destination fails at the move.
PolicyPlus/DownloadAdmx.vb:37
When the person is an administrator, a newly created language folder and every moved file are reset to inherit permissions from their parent; a newly created main destination folder is not reset, and an existing folder gets ownership taken.
PolicyPlus/DownloadAdmx.vb:55
When the download succeeds, the person is asked "ADMX files downloaded successfully. Open them now?"; only Yes makes the destination the new policy source folder to load. Either answer closes the dialog as accepted.

The download fetches one fixed Microsoft package, Administrative Templates for Windows 11 Sep 2026 Update (26H2), and takes definitions from its fixed folder inside the unpacked package.
PolicyPlus/DownloadAdmx.vb:84
Moving files into a destination replaces: any existing file with the same name is deleted first, then the new file is moved in. Missing destination folders are created.
PolicyPlus/DownloadAdmx.vb:52
The download copies the main definition files, then the language folder named after the person's regional-format setting in Windows (not the display language) if the package has one; a missing own-language folder is skipped. When that setting is not en-US it also copies the en-US folder as a fallback, and here the folder is required: if the package lacks it, the download fails at "move the ADMX files".
PolicyPlus/DownloadAdmx.vb:103
Only when the person is a Windows administrator and the destination folder already exists, the download first takes ownership of the destination, giving the Administrators group ownership and full control, and enables the take-ownership and restore privileges.
PolicyPlus/DownloadAdmx.vb:38
When the Windows Installer extraction of the downloaded package exits with any non-zero code, the download fails at the step "extract the package"; the downloaded installer file is deleted only after a successful extraction.
