Business rules for this screen (3)

Screens (3)
When OK is pressed, choosing 'clear first' or 'purge' is accepted without further input. Choosing 'delete one value' with an empty value name is refused with the message "You must enter a value name." and the dialog stays open. With no option chosen, nothing happens.
