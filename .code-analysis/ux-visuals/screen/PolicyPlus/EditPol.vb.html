Deleting a key opens a dialog with three choices; nothing is confirmed until one is selected, and Escape cancels. Purge empties the key: all its values are destroyed and the key is marked cleared. Delete-one writes a deletion entry for a typed value name and keeps the key's other contents; it is confirmed only when a name is typed, otherwise the person is told "You must enter a value name." and the dialog stays open.
