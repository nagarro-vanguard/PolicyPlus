When names are required in a list, confirming is refused if two entries share a name; the person is told 'Multiple entries are named "<name>"! Remove or rename all but one.' and keeps editing.

Confirming a list without names keeps the value of every row in order as a plain list, ignoring the unfinished blank row; a row takes only its value cell, never a name. Confirming a list with names keeps each name with its value.
