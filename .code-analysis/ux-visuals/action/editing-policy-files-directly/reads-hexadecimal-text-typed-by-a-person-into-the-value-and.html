In the hexadecimal number box, typed text is read as an unsigned hex number. If it is too large to read as a 64-bit number, or larger than the box's maximum (4294967295 for a 32-bit DWord), the box takes the maximum. Text that is not valid hex, including text with a minus sign, leaves the value unchanged. Empty text is ignored.
