Overview

System overview

Policy Plus is a Windows desktop editor for Group Policy administrative-template settings. It loads policy definition files into a searchable tree and reads or writes values in the live registry, user profiles or policy files. Administrators and power users use it, including on Windows Home, which lacks the built-in editor.

The layers in plain words

Screens
What a person sees and enters: Windows Forms windows and dialogs, their layout, the handlers that react to a person using them, and the small value shapes dialogs fill in and hand back to the main window.
Policy state logic and Windows interop
Decides which state each policy is in, reads and writes policy sources (POL files, REG files, the registry), parses policy-state scripts, and wraps Windows system calls, edition checks and privileges.
Policy definitions and data model
Reads policy definition and comment files, resolves their references and holds the result in memory for the screens.
Settings and configuration
Keeps the program's own choices in the current user's registry and pins the runtime version the program runs on.

Project work, not part of the product

Build tooling
Scripts a developer runs outside the application to prepare it for compiling.
