Deleting a key opens a dialog with three choices; nothing is confirmed until one is selected, and Escape cancels. Purge empties the key: all its values are destroyed and the key is marked cleared. Clear-first does the same, but first drops the key's old cleared mark so the new one sorts ahead of the values, then puts back the key's own values listed one level directly below it, skipping deletion markers and sub-key values. Delete-one writes a deletion entry for a typed value name and keeps the key's other contents; it is confirmed only when a name is typed, otherwise the person is told "You must enter a value name." and the dialog stays open. After any choice the list is rebuilt and the key is selected.
