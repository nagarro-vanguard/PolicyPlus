Business rules in this layer (30)

When the program starts, the sources for user and computer policies saved last time are opened. If opening them fails, the user is told "The previous policy sources are not accessible. The defaults will be loaded.", both sources are reset to the local group policy object, and those defaults are opened instead.

Saved definitions folder is opened at start. If the folder loads with errors, the user is shown the errors and asked whether to continue; answering No discards the folder.
PolicyPlus/Main.vb:62 · Screens: Main
When the saved definitions folder cannot be used and is not the Windows default folder, the user is offered the default folder instead. Answering No shows no further message and leaves the workspace empty. Answering Yes saves the default as the saved source before loading it, so it stays saved even if loading fails. Errors found loading the default are only reported, with no question to continue. If the default throws, or the failing folder was the default, the user is told "Policy definitions could not be loaded: " followed by the reason, and the workspace stays empty.

Each filter test applies only when its option is set. A policy is hidden when its managed-or-preference kind is the opposite of the wanted kind; its state does not match Configured, Not configured, Enabled or Disabled; its having a non-blank comment differs from the wanted value; or it is unsupported on the allowed products (judged by the always-match-any and match-blank-support options). Otherwise it is shown. With the comment option set, a viewed source that has no comment table (no comment file, or one that could not be read) makes the check fail with an unhandled error, not treat the policy as having no comment.
