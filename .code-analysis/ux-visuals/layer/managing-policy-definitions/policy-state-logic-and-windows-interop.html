Policy state logic and Windows interop

Decides which state each policy is in, reads and writes policy sources (POL files, REG files, the registry), parses policy-state scripts, and wraps Windows system calls, edition checks and privileges. In Managing policy definitions: 0 actions and 19 business rules. Part of its code is also used by other capabilities.
